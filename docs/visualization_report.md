# QuickBI 数据可视化分析报告

## 一、可视化整体设计

### 1.1 数据来源与处理链路

```
ODS 原始 CSV（OSS）
  rejected_2007_to_2018Q4.csv  (~2764万行)
  accepted_2007_to_2018Q4.csv  (~211万行)
        │
        │  EMR Serverless Spark
        │  01_build_viz_data.py      → 12 张聚合表
        │  02_build_enhanced_viz.py  →  3 张增强表
        ▼
  OSS viz 层（oss://lending-data/510/viz/）
        │
        │  ADB MySQL 3.0 外表导入
        ▼
  AnalyticDB MySQL（loan_data 数据库，15 张表）
        │
        │  QuickBI 数据集 + 仪表板
        ▼
  6 个 Tab，共 20+ 个图表
```

## 二、Tab 1：时间趋势

**数据集**：`viz_510_trend_monthly`（140行，2007–2018年月度）、`viz_510_year_risk_trend`（12行，年度汇总）

### 图表一：月度申请量趋势（折线图）

- **X 轴**：year_month（年月）
- **Y 轴**：rej_cnt（拒绝量）、acc_cnt（批准量）双线
- **核心发现**：
  - 2007–2010 年申请量较低且波动大，反映金融危机影响
  - 2013 年后申请量快速攀升，整体市场规模持续扩张
  - 拒绝量始终远高于批准量（约 11.8:1），平台审批标准较严格

### 图表二：月度批准率趋势（折线图）

- **X 轴**：year_month
- **Y 轴**：approval_rate（批准率）
- **核心发现**：
  - 整体批准率维持在 5%–10% 区间
  - 2012–2015 年批准率相对稳定，2016 年后略有波动
  - 宏观经济周期对批准率有明显影响

### 图表三：利率 vs 违约率双轴折线图（增强）

- **X 轴**：year（年份，2007–2018）
- **左 Y 轴**：avg_int_rate（平均利率，折线）
- **右 Y 轴**：charged_off_rate（违约率，折线，不同色）
- **核心发现**：
  - 利率与违约率呈现一定的正相关性，高利率年份往往伴随较高违约率
  - 2007–2009 年违约率显著偏高（金融危机影响）
  - 2013–2015 年两项指标均处于相对低位，是平台历史上风险最优区间
  - 2016–2018 年违约率小幅回升，而利率随美联储加息政策同步上行

## 三、Tab 2：审批驱动因素

**数据集**：`viz_510_approval_by_purpose/emp/dti/amnt`（四张独立聚合表）

### 图表四：贷款用途 vs 批准率（条形图）

- **维度**：purpose（14 种用途）
- **度量**：approval_rate（批准率）
- **核心发现**：
  - 汽车贷款（car）、婚礼（wedding）、家庭购置（house）批准率相对较高
  - 小企业贷款（small_business）批准率最低，风险评估要求最严格
  - 债务整合（debt_consolidation）申请量最大但批准率中等，是平台核心业务

### 图表五：工作年限 vs 批准率（柱状图）

- **维度**：emp_length_label（< 1 year 到 10+ years）
- **度量**：approval_rate（批准率）
- **核心发现**：
  - 工作年限与批准率呈明显正相关
  - 工作 10 年以上的申请者批准率显著高于 1 年以下的申请者
  - "Unknown"（未填写工作年限）的批准率处于低位，说明信息完整性影响审批

### 图表六：DTI 分段 vs 批准率（柱状图）

- **维度**：dti_bucket（0-10 / 10-20 / 20-30 / 30-40 / 40+）
- **度量**：approval_rate（批准率）
- **核心发现**：
  - DTI 与批准率呈强烈负相关，是最关键的审批因子之一
  - DTI < 10 的申请者批准率约为 DTI > 40 的申请者的 3–5 倍
  - 与建模结果相互印证：dti 是 GBT 模型第二重要的特征（贡献 12.2%）

### 图表七：申请金额分段 vs 批准率（柱状图）

- **维度**：amnt_bucket（< $5K 到 > $25K）
- **度量**：approval_rate（批准率）
- **核心发现**：
  - 申请金额与批准率不呈简单线性关系
  - 中等金额（$10–$20K）批准率略高于两端
  - 极高金额（> $25K）申请因风险敞口较大，批准率相对偏低

## 四、Tab 3：风险与收益

**数据集**：`viz_510_risk_grade_summary`（7行）、`viz_510_risk_grade_status`（28行）、`viz_510_purpose_grade_heatmap`（98行）

### 图表八：各信用等级违约率（柱状图）

- **维度**：grade（A–G）
- **度量**：charged_off_rate（违约率）
- **核心发现**：
  - 违约率从 A 到 G 单调递增，Grade A 违约率约 5%，Grade G 超过 30%
  - 等级系统对风险的区分度极高，验证了 LendingClub 信用评级体系的有效性

### 图表九：信用等级 vs 平均利率（折线图）

- **维度**：grade（A–G）
- **度量**：avg_int_rate（平均利率）
- **核心发现**：
  - 利率从 A（约 7%）到 G（约 27%）持续攀升，体现风险溢价定价逻辑
  - Grade A–B 利率差距较小，Grade E–G 利率差距扩大，高风险借款人面临显著更高成本

### 图表十：贷款状态分布堆积柱状图

- **X 轴**：grade（A–G）
- **Y 轴**：cnt（按 loan_status 分色：Fully Paid / Current / Charged Off / Late）
- **核心发现**：
  - Grade A–B 以 Fully Paid 为主，信用质量优良
  - Grade E–G 中 Charged Off 占比显著上升，坏账风险集中在低等级
  - Current 状态（还款中）在 B–C 等级占比最高，为平台当前主要在管资产

### 图表十一：贷款用途 × 信用等级违约率热力图（增强）

- **行**：purpose（14 种用途）
- **列**：grade（A–G）
- **颜色深浅**：charged_off_rate（违约率，越深越高）
- **核心发现**：
  - **高危组合**：small_business + Grade E/F/G，违约率超过 40%，风险极高
  - **低危组合**：car + Grade A/B，违约率低于 5%，是最优质的贷款组合
  - 同一用途下，等级越低违约率越高，但不同用途在同一等级的违约率差异也显著
  - renewable_energy 类即使在高等级中违约率也偏高，可能与项目收益不稳定有关
  - 该热力图揭示了**用途与等级的交互效应**，是单维度分析无法发现的深层规律

## 五、Tab 4：借款人画像

**数据集**：`viz_510_borrower_income`（6行）、`viz_510_borrower_home`（3行）、`viz_510_borrower_fico`（6行）

### 图表十二：收入分段违约率（柱状图）

- **维度**：income_bucket（< $30K 到 > $200K）
- **度量**：charged_off_rate（违约率）
- **核心发现**：
  - 违约率随收入增加整体下降，高收入借款人（> $120K）违约率最低
  - < $30K 收入段违约率最高，还款能力有限
  - $200K 以上收入段违约率略有回升，可能与高收入借款人倾向于申请更大金额有关

### 图表十三：房产状况分布（饼图）

- **维度**：home_ownership（OWN / RENT / MORTGAGE）
- **度量**：total_cnt（贷款数）
- **核心发现**：
  - MORTGAGE（按揭房）占比最大（约 50%），是主要借款人群体
  - RENT（租房）占比约 40%，说明平台服务了大量无房资产的借款人
  - OWN（全款房）占比最小（约 10%），但违约率最低

### 图表十四：信用评分段分布对比（柱状图）

- **维度**：score_bucket（< 600 到 800+）
- **度量**：acc_cnt（批准数）、rej_cnt（拒绝数）双柱对比
- **核心发现**：
  - 批准贷款集中在 FICO 660–750 分段，平台核心客群为中等信用人群
  - 低于 600 分的申请几乎全部被拒绝，信用底线明确
  - 高分段（750+）批准率高，但申请量相对偏少，高信用人群对 P2P 平台依赖度较低

## 六、Tab 5：贷款产品特征

**数据集**：`viz_510_loan_purpose_detail`（28行）、`viz_510_int_rate_trend`（84行）

### 图表十五：贷款用途 × 期限违约率矩阵（交叉表）

- **行**：purpose（14 种用途）
- **列**：term（36 months / 60 months）
- **值**：charged_off_rate（违约率）
- **核心发现**：
  - 几乎所有用途下，60 个月期限的违约率均高于 36 个月，长期贷款风险更高
  - small_business 60 个月违约率尤为突出（> 35%）
  - car 贷款两个期限违约率差异最小，是期限风险最稳定的用途

### 图表十六：历年各等级平均利率趋势（多线折线图）

- **X 轴**：year（2007–2018）
- **Y 轴**：avg_int_rate（按 grade 分 7 条线）
- **核心发现**：
  - A–G 等级利率曲线始终保持稳定的层级间距，定价体系一致性高
  - 2013–2015 年整体利率处于低位，之后随市场利率环境上行
  - 低等级（E–G）利率波动幅度更大，对宏观利率环境更敏感

## 七、Tab 6：地理分析（增强）

**数据集**：`viz_510_geo_map`（51行，含 DC）

### 图表十七：美国各州贷款批准率色彩地图

- **地理字段**：state_name（州英文全称，QuickBI 自动匹配地图边界）
- **颜色深浅**：approval_rate（批准率）
- **核心发现**：
  - 东西海岸主要州（CA、NY、FL、TX）申请量最大，但批准率处于中等水平
  - 中部内陆州（如 IA、NE、SD）批准率相对较高，可能与申请人负债结构更保守有关
  - 批准率的地域差异验证了 DWS 层 state_approval_rate 特征的信息量（在 GBT 模型中重要性达 73.6%）

### 图表十八：各州贷款气泡图

- **X 轴**：approval_rate（批准率）
- **Y 轴**：avg_dti（平均债务收入比）
- **气泡大小**：total_cnt（申请总量）
- **标签**：state_code（州缩写）
- **核心发现**：
  - 申请量最大的州（CA、TX、NY、FL）气泡最大，集中在图表中部区域
  - 高批准率 + 低 DTI 的州（右下角）是风险最优区域
  - 低批准率 + 高 DTI 的州（左上角）存在较高信用风险集中度
  - 气泡图直观展示了三维关系，揭示了单一地图无法呈现的批准率与债务负担的权衡

## 八、可视化设计总结

### 8.1 数据处理规模

| 指标 | 数值 |
|------|------|
| 原始数据总量 | 27,893,000 行（约 2789 万） |
| EMR 处理耗时 | 01脚本 144s + 02脚本 ~120s |
| 生成聚合表 | 15 张（最小 3 行，最大 140 行） |
| 仪表板 Tab 数 | 6 个 |
| 图表总数 | 18 个 |

### 8.2 图表类型分布

| 图表类型 | 数量 | 用途 |
|---------|------|------|
| 折线图 | 6 | 时间趋势、等级趋势 |
| 柱状图 / 条形图 | 7 | 分类维度对比 |
| 堆积柱状图 | 1 | 构成比例分析 |
| 热力图 | 1 | 二维交叉风险矩阵 |
| 饼图 | 1 | 占比分布 |
| 色彩地图 | 1 | 地理空间分布 |
| 气泡图 | 1 | 三维关系探索 |

### 8.3 核心分析结论

1. **地理因素是最强的审批预测信号**：州批准率（state_approval_rate）在机器学习模型中重要性达 73.6%，地图可视化直观验证了各州之间的显著差异，说明地域信贷文化和经济环境对审批有深远影响。

2. **DTI 是可控风险的核心指标**：DTI 分段批准率图和 GBT 特征重要性（12.2%）一致表明，债务收入比是申请人最应关注的优化方向。

3. **等级体系有效区分风险**：从热力图和违约率柱状图可以看出，LendingClub 的 A–G 等级体系与实际违约率高度对应，Grade A/B 的投资价值显著优于 Grade E/F/G。

4. **期限选择影响违约风险**：用途×期限矩阵显示，几乎所有用途的 60 个月贷款违约率均高于 36 个月，借款人应尽量选择短期贷款以降低违约概率。

5. **宏观经济周期与贷款风险联动**：双轴折线图显示 2008–2009 年违约率峰值与金融危机时间窗口吻合，2013–2015 年为历史最优风险区间，说明平台风险指标对宏观周期敏感。
